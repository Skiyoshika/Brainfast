### P2 — v0.5+ nice-to-have

#### Narrow the final 4 broad excepts
- **Locations:** [project/frontend/server_context.py](project/frontend/server_context.py) lines 726, 1042, 1124, 1180
- **Why they're special:** all four are background-worker wrapper try/except that MUST catch any exception to set task state (`learning_state["error"]`, `job_state["error"]`, autopick task error). Broad `except Exception` is CORRECT here.
- **Only action needed:** add an inline comment noting the intentional breadth (so future linters don't touch them):

```python
try:
    ...
except Exception as e:  # noqa: BLE001  # worker must trap all to set task state
    task.update({"status": "error", "error": str(e)})
```

## Known Gotchas (lessons from this session)

1. **The 04-20 plan checkboxes lied.** Commits `3ec553b → 684011d` had landed the work, but the plan's `- [ ]` boxes were never flipped. Lesson: always audit *commits on branch*, not just plan status.

2. **Commit `ae188bc` on 2026-04-08 resolved all 13 UX review issues.** Initial audit treated the 04-08 review as open issues. Verify commit history before listing "bugs to fix".

3. **`waitress` was not in deps until now.** If anyone uses an old local install, `pip install -e .` picks it up from `pyproject.toml`. For end-users, `Start_Brainfast.bat` runs `pip install -e .` implicitly if needed — no manual step.

4. **`project/version.json` is already `1.0.0-rc1`.** Don't bump lower. CITATION.cff was lagging at `0.3.0-desktop`; I aligned it.

5. **Full unit suite is slow locally (>5 min).** Don't rely on local full runs — push to CI. Use the 120-test targeted subset for inner-loop development (26 s).

6. **Playwright MCP extension is not installed** in this workspace — browser automation for README screenshots has to be done manually or via Claude Preview (which doesn't save to disk).

7. **The 4 remaining `except Exception` blocks are intentional.** Do not narrow them without understanding they're worker wrappers. See [P2 § Narrow the final 4 broad excepts](#narrow-the-final-4-broad-excepts).

8. **Port 8787 can get stuck after a crashed server.** If preview_start complains, run `netstat -ano | grep :8787 | grep LISTEN` and kill the PID manually.

9. **The docs/ cleanup moved UX_FEEDBACK docs to archive.** If you need to reference the 04-08 review, it's at `docs/archive/UX_FEEDBACK_NEUROBIOLOGIST_2026-04-08.md`, NOT `docs/` root.
