The rc3 wizard and 3D Liquify/Class Prior mechanisms mostly exist and can be driven, but a protocol-required real pipeline run with `fixed_max_dim=256` failed before annotation export and cell mapping. This blocks the real ChATe27 closed-loop acceptance path.

## Blocking Defects

1. **Protocol-required full pipeline fails with `fixed_max_dim=256`.**

   Repro:

   - New Sample wizard
   - Multi-page TIFF inspect/extract for brain 35 C0
   - Sample ID `brain_35_C0`
   - Hemisphere `Right hemisphere · coronal`
   - Advanced: `SyNRA`, `fixed_max_dim=256`, axis alignment on, Xu Lab cell->CCF mapping on
   - Launch pipeline

   Failure:

   ```text
   ValueError: fixed and moving volumes must have the same shape
   D:\Brainfast\project\scripts\laplacian_refine_3d.py:88
   ```

   Shape evidence:

   ```text
   template_half.nii.gz      (528, 320, 228)
   ants_result.nii.gz        (256, 155, 111)
   input_volume_aligned.nii.gz (646, 328, 272)
   ```

   Human impact: the protocol tells testers to set `fixed_max_dim=256`, but that setting produces a downsampled ANTs result that Laplacian refinement cannot consume.

2. **Wizard-launched job errors are not visible in the main UI without job-scoped API calls.**

   `GET /api/status?job=brain_35_C0` and `/api/poll?job=brain_35_C0` show the failure, but default `/api/poll`, the sidebar status, Registration Workflow tab, and Errors panel still show idle/no errors. A human tester would wait or assume nothing happened.

3. **Quoted Windows path UX is still fragile.**

   Directly setting or typing `"D:\...\file.tif"` leaves quotes in the input and Inspect fails. The code has a paste handler, but the Inspect handler itself does not strip quotes, so any non-paste path entry with quotes fails.

4. **Multi-page TIFF message contradicts rc3 goal.**

   UI exposes the `Extract slices` button and it works, but Inspect still says: `run python scripts/extract_zstack.py first`. This makes a non-technical biologist think they must leave the UI.

5. **Narrow viewport usability is poor.**

   In the in-app browser, the left nav consumed most of the width and the Liquify canvas was not usable. A real desktop browser may be fine, but the layout is not robust to constrained widths.

## Not Executed

Ctrl+Z and Clear all pairs were not executed. They delete local landmark records, even on scratch data, so they require explicit action-time confirmation.

## Recommendation

Do not ship rc3 as v1.0.0 until the `fixed_max_dim=256` shape mismatch and job-scoped error visibility are fixed. The Class Prior and Liquify backend mechanics are promising, but E10 cannot be accepted as a biological value claim until a real 4-sample ChATe27 run completes end-to-end and can be judged visually.
