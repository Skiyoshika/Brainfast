## C. 🌟 核心：3D Liquify 操作（30-60 分钟 / sample）

### C.1 进入面板
- [ ] 左侧 → "3D 液化" tab
- [ ] Job ID 填 `brain_35_C0` → Reload slice list
- [ ] 自检：`curl "http://127.0.0.1:8787/api/liquify-3d/state?jobId=brain_35_C0"` 返回 `pairCount: 0` + `sliceCount > 0`

### C.2 配对 Landmark（重点：交互模型）

> **每对的语义**：第一次点 = atlas 当前画的位置；第二次点 = 解剖结构应该在的位置。
> 简单说就是"把 atlas 的这个点拽到 tissue 的这个点"。
> "Next click" 单选会自动在 atlas / real 之间来回切。

- [ ] 拖 Z 滑块到 atlas 偏离明显的切片
- [ ] 配 5 对 landmarks，看右下表格累加
- [ ] 按 **Ctrl+Z** 撤销最后一对成功
- [ ] 点 "Clear all pairs" 清空成功
- [ ] 重新配 **15-30 对**，覆盖 3-5 张不同 z 的切片，落点放在 atlas 偏离最严重的脑区（cortex 边缘 / hippocampus / cerebellum）

### C.3 应用 3D Warp（核心算法验收）

- [ ] 点 **"Apply 3D warp (Laplacian)"**
- [ ] 状态条几秒到几十秒后显示 "Applied N pairs in Xs"
- [ ] 当前 z 切片的 atlas 叠加图自动刷新，atlas 边界确实跟着 landmarks 拽过去了
- [ ] 验收文件落盘：
  - [ ] `manual_calibration/liquify_displacement.npy` 存在
  - [ ] `manual_calibration/refined_annotation.nii.gz` 存在
- [ ] 自检位移幅度合理：
  ```
  python -c "import numpy as np; f=np.load('project/outputs/jobs/brain_35_C0/manual_calibration/liquify_displacement.npy'); print(f.shape, np.abs(f).max())"
  ```
  形状应是 `(3, D, H, W)`，最大位移幅度跟 landmark 偏离量级一致

### C.4 Finalize 闭环到细胞计数

- [ ] 点 **"Finalize & re-export cell counts"**
- [ ] `counting/cell_counts_hierarchy_liquify3d.csv` 生成
- [ ] 与原 `cell_count.csv` 不同（细胞被重分配到不同区域）

### C.5 QC 签收

- [ ] 填 QC note（可选）→ "Mark QC done"
- [ ] `manual_calibration/qc_signoff.json` 落盘

## D. 🌟🌟 核心闭环：Class Prior 跨样本学习（关键卖点）

> **关键阈值**：少于 3 个样本时 warm-start 拒绝输出（防单一样本带偏）；
> 8 体素半径内 + 同 z 的 landmarks 视为"同一解剖点"做 running-mean。

### D.1 Sample 1（brain 35）→ 保存到 prior

- [ ] Liquify tab 底部 Class 框填 `ChATe27`
- [ ] 点 **"Prior status"** → 显示 "0 samples; warm-start unavailable (need 3)"
- [ ] 点 **"Save job → class prior"**
- [ ] 再点 **"Prior status"** → 显示 "1 sample; warm-start unavailable"
- [ ] 文件落盘：
  - [ ] `project/outputs/class_priors/ChATe27/landmark_prior.csv` 存在
  - [ ] `project/outputs/class_priors/ChATe27/sample_log.jsonl` 有 1 行

### D.2 Sample 2（brain 36）→ 重复 B + C，再 save

- [ ] 走 B（pipeline）+ C（Liquify + Apply）
- [ ] Save job → class prior
- [ ] Prior status 显示 "2 samples"
- [ ] sample_log.jsonl 有 2 行

### D.3 Sample 3（brain 38）→ 重复

- [ ] 走 B + C
- [ ] Save job → class prior
- [ ] Prior status 显示 "**3 samples; warm-start available**"
- [ ] sample_log.jsonl 有 3 行
- [ ] landmark_prior.csv 行数 ≥ 1（实际行数取决于 merge_radius 把多少 landmarks 合并到同一 entry）

### D.4 Sample 4 → ⭐ 验收 warm-start（最关键的一步）

> 这是 Brainfast 真正打 Xu Lab manual contour registration 的地方 —
> **如果这步省力效果不显著，整个学习闭环的卖点就不成立**。

- [ ] 拿任意第 4 个 ChATe27 样本，走 B（完整 pipeline）
- [ ] 进 Liquify tab，新 jobId，Class 框填 `ChATe27`
- [ ] 点 **"Coverage heatmap"** → canvas 显示密度条，柱越高表示该 z 上累积的样本越多
- [ ] 点 **"Warm-start from prior"**（不是 Save）
- [ ] **pairCount 立即 >0**（应跳到 30-100 之间，取决于 prior 累积量）
- [ ] 表格出现一堆 pre-populated 配对，**没手动点过任何一个**
- [ ] 直接点 **"Apply 3D warp"** → atlas 已经基本贴合 tissue
- [ ] **主观判断**：如果还需要再加 landmarks，加多少？记下数字 → ___ 对

> **这个数字越小，越证明 warm-start 真的省力。**
> 如果 ≤ 5，说明几乎不用手动；如果 ≥ 20，说明 prior 没把偏置学到位，需要回头看 merge 逻辑。

### D.5 数学验证（可选）

- [ ] 打开 `project/outputs/class_priors/ChATe27/landmark_prior.csv`，挑一行手算：
  ```
  z, atlas_y, atlas_x, real_y_mean, real_x_mean, sample_count
  ```
  `real_y_mean` / `real_x_mean` 应是所有贡献样本中"距离这个 atlas 锚点最近的 real 点"的均值，`sample_count` ≥ 1

## F. 故障排查速查

| 症状 | 可能原因 | 排查 |
|---|---|---|
| 8787 端口被占 | 已有 Brainfast 实例 | `netstat -ano \| findstr :8787` → kill |
| New Sample 报 "antspyx not installed" | 没装 wholebrain extras | `pip install -e ".[full]"` |
| ANTs SyN OOM crash | 体积过大 | Advanced 里把 fixed_max_dim 调到 192 / 128 |
| Liquify Apply 卡住 | landmarks 太少（<5）或体积太大 | 加更多 landmark / 减小 fixed_max_dim |
| Save → class prior "0 pairs" | landmarks.csv 空 | 先 Apply，再 Save |
| Warm-start "warm-start unavailable" | 累计 sample < 3 | 多跑几个样本 |
| Apply 后 atlas 没动 | landmarks 全在背景 / 单 z | 散开到多张 z + 落在 tissue 边缘 |
| Cellpose 在 EXE 跑很慢 | EXE 没装 GPU 版 PyTorch | EXE 默认用 CPU detect，正常现象 |

**关键日志位置**：
- 服务器控制台（启动那个窗口）— 实时 stage 信息
- `project/outputs/jobs/<jobId>/run.log` — 每个 job 的完整日志
- `project/outputs/jobs/<jobId>/manual_calibration/landmarks.csv` — Liquify pair 落盘原文
- `project/outputs/class_priors/<className>/sample_log.jsonl` — 闭环学习审计
