#### Narrow the final 4 broad excepts
- **Locations:** [project/frontend/server_context.py](project/frontend/server_context.py) lines 726, 1042, 1124, 1180
- **Why they're special:** all four are background-worker wrapper try/except that MUST catch any exception to set task state (`learning_state["error"]`, `job_state["error"]`, autopick task error). Broad `except Exception` is CORRECT here.
- **Only action needed:** add an inline comment noting the intentional breadth (so future linters don't touch them):

```python
try:
```

## Known Gotchas (lessons from this session)

1. **The 04-20 plan checkboxes lied.** Commits `3ec553b → 684011d` had landed the work, but the plan's `- [ ]` boxes were never flipped. Lesson: always audit *commits on branch*, not just plan status.

2. **Commit `ae188bc` on 2026-04-08 resolved all 13 UX review issues.** Initial audit treated the 04-08 review as open issues. Verify commit history before listing "bugs to fix".

3. **Pre-existing tests can break when you change a default.** Switching `main()` from `app.run` to `waitress.serve` made `test_server_main_checks_port_before_running_app` (in [test_app_metadata.py:94](../../../project/tests/unit/test_app_metadata.py) — commit `684011d`) actually start a real server and block for 6h on CI. Lesson: when you change the default path, grep **all** tests that mock the old default (`Grep -r "app.run\|app\\.run"` in tests/). Fix: add `monkeypatch.setenv("BRAINFAST_DEV", "1")` to pin the old path, or patch `waitress.serve` alongside `app.run`.

4. **My first diagnosis was wrong.** I blamed `patch("builtins.__import__")` (commit `cfe9a79`). That patch IS genuinely risky but wasn't the culprit — the pre-existing test in #3 was. Lesson: when CI hangs at 6h, **reproduce locally with pytest-timeout** before guessing. Add `--timeout=300` to pyproject addopts and the real failing test surfaces in seconds.

5. **`waitress` was not in deps until now.** `pip install -e .` picks it up from `pyproject.toml`. For end-users, `Start_Brainfast.bat` runs `pip install -e .` implicitly — no manual step.

6. **`project/version.json` is already `1.0.0-rc1`.** Don't bump lower. CITATION.cff was lagging at `0.3.0-desktop`; I aligned it.

7. **Per-test timeout must be ≥300s.** Cellpose's CPSAM model download (~120MB on first run) takes >60s on GitHub-hosted Windows. The current `addopts = "-v --timeout=300 --timeout-method=thread"` is the right balance: fast enough to catch real hangs, slow enough for one-shot network I/O.

8. **Full unit suite is ~53s locally (not slow).** Earlier I thought it was >5 min and only ran a 120-test subset. That was wrong — the full 428-test suite runs in 53s with `--cov` after the `test_app_metadata.py` fix. Use the full suite for local verification.

9. **Playwright MCP extension is not installed** in this workspace — browser automation for README screenshots has to be done manually or via Claude Preview (which doesn't save to disk).

10. **The 4 remaining `except Exception` blocks are intentional.** Do not narrow them without understanding they're worker wrappers. See [P2 § Narrow the final 4 broad excepts](#narrow-the-final-4-broad-excepts).

11. **Port 8787 can get stuck after a crashed server.** If preview_start complains, run `netstat -ano | grep :8787 | grep LISTEN` and kill the PID manually.

12. **The docs/ cleanup moved UX_FEEDBACK docs to archive.** If you need to reference the 04-08 review, it's at `docs/archive/UX_FEEDBACK_NEUROBIOLOGIST_2026-04-08.md`, NOT `docs/` root.

13. **Repo was renamed IdleBrain → Brainfast during this session.** Remote URL already updated locally via `git remote set-url`. If a fresh clone uses the old URL, GitHub redirects but flags a warning — run the remote-set-url to silence it.
